2. Анализ проблемы с "Памятью" (remember_file)
Ты прав, мы весь вечер боролись с таймаутами. Сейчас ситуация выглядит так:
1.	Агент вызывает инструмент: Агент правильно распознает команду "Запомни файл..." и вызывает инструмент remember_file. Это работает.
2.	GUI отправляет запрос: main_window.py отправляет запрос в бэкенд. Тоже работает.
3.	Бэкенд зависает на чтении: main.py (эндпоинт /mcp/remember_file) принимает запрос, НО далее происходит одно из двух (или оба сразу):
o	Проблема А (Таймаут): Чтение и сохранение файла (особенно .docx) занимает время. Мы попытались решить это через асинхронность (asyncio.create_task), но, видимо, бэкенд всё ещё ждёт завершения задачи, прежде чем вернуть ответ GUI. Либо мы не закрыли соединение, либо задача ещё не завершилась, а таймаут уже сработал.
o	Проблема Б (Логика): Мы решили не хранить большие файлы в БД, а копировать их в папку knowledge/ агента и хранить в БД только путь. Вчерашняя реализация process_remember_file, возможно, была неполной или мы её не подключили к эндпоинту. Агент не видит этот "путь" в истории задачи.
Суть проблемы: Система пытается сделать слишком много за один раз (прочитать большой файл, распарсить его, сохранить в БД, скопировать в папку) и не укладывается в таймауты. Это архитектурная ошибка.
Моё предложение (текстовое описание):
Мы не будем делать remember_file синхронным или асинхронным в рамках одного запроса. Мы сделаем его "задачей с отсроченным результатом".
1.	Шаг 1. Быстрый старт: Пользователь говорит "Запомни файл...". Бэкенд мгновенно (менее 1 сек) отвечает: "Ок, файл поставлен в очередь на запоминание. ID задачи: 123". И тут же создает в БД запись о том, что файл начал обрабатываться.
2.	Шаг 2. Фоновая обработка: В фоне запускается процесс, который читает файл, парсит, сохраняет в knowledge/, и, если нужно, добавляет в БД системное сообщение с кратким содержимым/ссылкой.
3.	Шаг 3. Проверка статуса: GUI может периодически проверять статус этой фоновой задачи по ID (например, каждые 5 секунд).
4.	Шаг 4. Готовность: Когда задача завершена, агент (или пользователь) может задать вопрос, и агент, увидев в истории ссылку на файл в knowledge/, сможет его прочитать и ответить.
Что это даёт:
•	Никаких таймаутов: GUI получает мгновенный ответ.
•	Масштабируемость: Можно обрабатывать файлы любого размера.
•	Память: Мы четко разделяем "запоминание" (фоновая задача) и "использование" (запрос агента).

В mcp_tools.py метод remember_file вызывает эндпоинт /mcp/remember_file с timeout=600. В main.py эндпоинт /mcp/remember_file вызывает process_remember_file как фоновую задачу (asyncio.create_task) и возвращает ответ мгновенно.
Но проблема в том, что в _process_mcp_command в main_window.py мы вызываем exec_response = requests.post(..., timeout=900). Бэкенд возвращает ответ мгновенно (потому что асинхронный), но GUI всё равно ждёт 900 секунд и падает по таймауту.
Где именно ошибка:
В /mcp/execute (main.py) в блоке elif tool_name == "remember_file" мы вызываем:
python
response = requests.post(url, json=payload, timeout=600)
Но мы не получаем ответ от /mcp/remember_file, потому что он возвращает {"status": "ok", "async": True} мгновенно, а не ждёт завершения process_remember_file.
То есть: таймаут срабатывает в /mcp/execute, потому что он ждёт ответ от /mcp/remember_file, но тот возвращает ответ мгновенно. В чём же проблема?

"Цифровой работник" — это АРМ (Автоматизированное Рабочее Место) для работы с ИИ-агентами, которые помогают в аналитике и разработке на платформе 1С:Предприятие.

o	Это экономит токены, ускоряет ответ и позволяет работать с файлами любого размера.
3.	Мгновенный ответ GUI (из опыта с асинхронностью):

"""
Модуль управления памятью агента (индексация и поиск)
Реализует архитектуру "Три слоя": Файлы → Индексы → Поиск
"""
import os
import json
import time
import sqlite3
import hashlib
from pathlib import Path
from typing import List, Dict, Any, Optional
from datetime import datetime

# Для работы с текстом и эмбеддингами
try:
    from sentence_transformers import SentenceTransformer
    import numpy as np
    EMBEDDINGS_AVAILABLE = True
except ImportError:
    EMBEDDINGS_AVAILABLE = False
    print("⚠️ sentence-transformers не установлена, поиск будет работать в режиме FTS5")

# Для работы с документами
try:
    from docx import Document
except ImportError:
    Document = None


class MemoryManager:
    """
    Управляет памятью агента: индексация файлов и поиск по ним.
    """
    
    def __init__(self, data_root: Path):
        self.data_root = Path(data_root)
        self.skills_root = self.data_root / "skills"
        self.db_path = self.data_root / "memory_index.db"
        
        # Инициализация векторной модели (если доступна)
        self.embedding_model = None
        if EMBEDDINGS_AVAILABLE:
            try:
                # Используем легкую модель для эмбеддингов
                self.embedding_model = SentenceTransformer('all-MiniLM-L6-v2')
                print("✅ Модель эмбеддингов загружена")
            except Exception as e:
                print(f"⚠️ Ошибка загрузки модели эмбеддингов: {e}")
                self.embedding_model = None
        
        # Инициализация БД
        self._init_db()
    
    def _init_db(self):
        """Создаёт таблицы для хранения индекса памяти."""
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        # Таблица файлов в памяти
        cursor.execute("""
            CREATE TABLE IF NOT EXISTS memory_files (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                agent_name TEXT NOT NULL,
                original_path TEXT NOT NULL,
                stored_path TEXT NOT NULL,
                filename TEXT NOT NULL,
                file_hash TEXT NOT NULL,
                file_size INTEGER,
                status TEXT DEFAULT 'pending',  -- pending, indexing, indexed, failed
                indexed_at DATETIME,
                created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
                UNIQUE(agent_name, original_path)
            )
        """)
        
        # Таблица чанков (кусков текста)
        cursor.execute("""
            CREATE TABLE IF NOT EXISTS memory_chunks (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                file_id INTEGER NOT NULL,
                chunk_index INTEGER NOT NULL,
                content TEXT NOT NULL,
                embedding BLOB,  -- для векторного поиска
                fts_content TEXT, -- для FTS5 поиска
                FOREIGN KEY (file_id) REFERENCES memory_files(id) ON DELETE CASCADE
            )
        """)
        
        # Таблица поиска (FTS5 для быстрого текстового поиска)
        cursor.execute("""
            CREATE VIRTUAL TABLE IF NOT EXISTS memory_fts 
            USING fts5(content, tokenize='porter unicode61')
        """)
        
        # Таблица статусов задач
        cursor.execute("""
            CREATE TABLE IF NOT EXISTS memory_queue (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                file_id INTEGER NOT NULL,
                status TEXT DEFAULT 'pending',
                started_at DATETIME,
                completed_at DATETIME,
                error TEXT,
                FOREIGN KEY (file_id) REFERENCES memory_files(id)
            )
        """)
        
        conn.commit()
        conn.close()
    
    def queue_file_for_indexing(self, agent_name: str, file_path: Path) -> int:
        """
        Копирует файл в хранилище агента и ставит в очередь на индексацию.
        Возвращает ID записи.
        """
        # 1. Создаём папку агента
        agent_memory_path = self.skills_root / agent_name / "knowledge"
        agent_memory_path.mkdir(parents=True, exist_ok=True)
        
        # 2. Копируем файл
        stored_path = agent_memory_path / file_path.name
        import shutil
        shutil.copy2(file_path, stored_path)
        
        # 3. Вычисляем хеш файла
        file_hash = self._compute_file_hash(file_path)
        file_size = file_path.stat().st_size
        
        # 4. Сохраняем в БД
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        cursor.execute("""
            INSERT OR REPLACE INTO memory_files 
            (agent_name, original_path, stored_path, filename, file_hash, file_size, status, created_at)
            VALUES (?, ?, ?, ?, ?, ?, 'pending', CURRENT_TIMESTAMP)
        """, (agent_name, str(file_path), str(stored_path), file_path.name, file_hash, file_size))
        
        file_id = cursor.lastrowid
        
        # 5. Ставим задачу в очередь
        cursor.execute("""
            INSERT INTO memory_queue (file_id, status, started_at)
            VALUES (?, 'pending', NULL)
        """, (file_id,))
        
        conn.commit()
        conn.close()
        
        print(f"📥 Файл '{file_path.name}' поставлен в очередь на индексацию (ID: {file_id})")
        return file_id
    
    def process_queue(self, batch_size: int = 1):
        """
        Обрабатывает очередь индексации (запускается в фоне).
        """
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        # Находим задачи со статусом pending
        cursor.execute("""
            SELECT q.id, f.id, f.stored_path, f.filename, f.agent_name
            FROM memory_queue q
            JOIN memory_files f ON q.file_id = f.id
            WHERE q.status = 'pending'
            LIMIT ?
        """, (batch_size,))
        
        tasks = cursor.fetchall()
        
        for task in tasks:
            queue_id, file_id, stored_path, filename, agent_name = task
            
            # Обновляем статус
            cursor.execute("""
                UPDATE memory_queue 
                SET status = 'processing', started_at = CURRENT_TIMESTAMP 
                WHERE id = ?
            """, (queue_id,))
            conn.commit()
            
            try:
                # Индексируем файл
                self._index_file(file_id, Path(stored_path))
                
                # Обновляем статус на success
                cursor.execute("""
                    UPDATE memory_queue 
                    SET status = 'completed', completed_at = CURRENT_TIMESTAMP 
                    WHERE id = ?
                """, (queue_id,))
                conn.commit()
                
                print(f"✅ Файл '{filename}' успешно проиндексирован")
                
            except Exception as e:
                # Обновляем статус на error
                error_msg = str(e)
                cursor.execute("""
                    UPDATE memory_queue 
                    SET status = 'failed', error = ?, completed_at = CURRENT_TIMESTAMP 
                    WHERE id = ?
                """, (error_msg, queue_id))
                conn.commit()
                
                cursor.execute("""
                    UPDATE memory_files 
                    SET status = 'failed' 
                    WHERE id = ?
                """, (file_id,))
                conn.commit()
                
                print(f"❌ Ошибка индексации файла '{filename}': {error_msg}")
        
        conn.close()
    
    def _index_file(self, file_id: int, file_path: Path):
        """
        Читает файл, разбивает на чанки и индексирует.
        """
        # 1. Читаем содержимое
        content = self._read_file_content(file_path)
        if not content:
            raise ValueError("Файл пуст или не содержит текста")
        
        # 2. Разбиваем на чанки (по 200-300 токенов)
        chunks = self._split_into_chunks(content)
        
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        # 3. Сохраняем чанки
        for i, chunk in enumerate(chunks):
            # Вычисляем эмбеддинг (если доступно)
            embedding_blob = None
            if self.embedding_model:
                try:
                    embedding = self.embedding_model.encode(chunk[:512])  # Ограничиваем длину
                    embedding_blob = np.array(embedding, dtype=np.float32).tobytes()
                except Exception as e:
                    print(f"⚠️ Ошибка вычисления эмбеддинга: {e}")
            
            # Сохраняем чанк
            cursor.execute("""
                INSERT INTO memory_chunks (file_id, chunk_index, content, embedding, fts_content)
                VALUES (?, ?, ?, ?, ?)
            """, (file_id, i, chunk, embedding_blob, chunk))
        
        # 4. Добавляем в FTS таблицу
        for chunk in chunks:
            cursor.execute("INSERT INTO memory_fts (content) VALUES (?)", (chunk,))
        
        # 5. Обновляем статус файла
        cursor.execute("""
            UPDATE memory_files 
            SET status = 'indexed', indexed_at = CURRENT_TIMESTAMP 
            WHERE id = ?
        """, (file_id,))
        
        conn.commit()
        conn.close()
        
        print(f"   📄 Проиндексировано {len(chunks)} чанков")
    
    def search(self, agent_name: str, query: str, limit: int = 5) -> List[Dict[str, Any]]:
        """
        Выполняет поиск по памяти агента.
        Возвращает список найденных чанков.
        """
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        # 1. Сначала пробуем векторный поиск (если есть эмбеддинги)
        results = []
        
        if self.embedding_model:
            try:
                query_embedding = self.embedding_model.encode(query)
                results = self._vector_search(cursor, query_embedding, agent_name, limit)
            except Exception as e:
                print(f"⚠️ Ошибка векторного поиска: {e}")
        
        # 2. Если векторный поиск не дал результатов или недоступен — используем FTS5
        if not results:
            results = self._fts_search(cursor, query, agent_name, limit)
        
        conn.close()
        return results
    
    def _vector_search(self, cursor, query_embedding, agent_name: str, limit: int) -> List[Dict[str, Any]]:
        """Векторный поиск по эмбеддингам."""
        # Преобразуем в numpy
        import numpy as np
        query_vec = np.array(query_embedding, dtype=np.float32)
        
        # Загружаем все чанки для агента (в реальном проекте используем FAISS)
        cursor.execute("""
            SELECT c.id, c.content, c.embedding
            FROM memory_chunks c
            JOIN memory_files f ON c.file_id = f.id
            WHERE f.agent_name = ? AND f.status = 'indexed' AND c.embedding IS NOT NULL
        """, (agent_name,))
        
        results = []
        for row in cursor.fetchall():
            chunk_id, content, embedding_blob = row
            if embedding_blob:
                embedding = np.frombuffer(embedding_blob, dtype=np.float32)
                # Косинусное расстояние
                similarity = np.dot(query_vec, embedding) / (np.linalg.norm(query_vec) * np.linalg.norm(embedding) + 1e-8)
                results.append({
                    "id": chunk_id,
                    "content": content,
                    "score": float(similarity)
                })
        
        # Сортируем по убыванию схожести
        results.sort(key=lambda x: x["score"], reverse=True)
        return results[:limit]
    
    def _fts_search(self, cursor, query: str, agent_name: str, limit: int) -> List[Dict[str, Any]]:
        """Поиск через FTS5 (быстрый текстовый)."""
        # Экранируем спецсимволы для FTS5
        query = query.replace('"', '').replace("'", "")
        
        cursor.execute("""
            SELECT c.id, c.content, f.filename, f.agent_name
            FROM memory_fts fts
            JOIN memory_chunks c ON c.fts_content = fts.content
            JOIN memory_files f ON c.file_id = f.id
            WHERE f.agent_name = ? AND f.status = 'indexed' 
            AND memory_fts MATCH ?
            ORDER BY rank
            LIMIT ?
        """, (agent_name, query, limit))
        
        results = []
        for row in cursor.fetchall():
            results.append({
                "id": row[0],
                "content": row[1],
                "filename": row[2],
                "agent_name": row[3],
            })
        
        return results
    
    def _read_file_content(self, file_path: Path) -> str:
        """Читает содержимое файла в зависимости от расширения."""
        ext = file_path.suffix.lower()
        
        if ext in ['.txt', '.md']:
            with open(file_path, 'r', encoding='utf-8') as f:
                return f.read()
        
        elif ext == '.docx':
            if Document is None:
                raise ImportError("python-docx не установлена")
            doc = Document(file_path)
            return "\n".join([para.text for para in doc.paragraphs])
        
        else:
            # Пытаемся прочитать как текст
            try:
                with open(file_path, 'r', encoding='utf-8') as f:
                    return f.read()
            except:
                raise ValueError(f"Неподдерживаемый формат файла: {ext}")
    
    def _split_into_chunks(self, text: str, chunk_size: int = 300) -> List[str]:
        """Разбивает текст на чанки примерно по chunk_size слов."""
        words = text.split()
        chunks = []
        
        for i in range(0, len(words), chunk_size):
            chunk = " ".join(words[i:i+chunk_size])
            chunks.append(chunk)
        
        return chunks
    
    def _compute_file_hash(self, file_path: Path) -> str:
        """Вычисляет SHA-256 хеш файла."""
        sha256 = hashlib.sha256()
        with open(file_path, 'rb') as f:
            for block in iter(lambda: f.read(4096), b''):
                sha256.update(block)
        return sha256.hexdigest()

    """Инициализирует БД по указанному пути. Вызывается после выбора пути пользователем."""

def parse_interview_file(file_path: Path) -> Dict[str, str]:
    """
    Парсит файл интервью и извлекает данные по разделам.
    Ожидаемый формат:

    ## 1. ОРГАНИЗАЦИОННЫЙ_ОБЪЕМ
    Текст раздела...

    ## 2. ОБЩИЕ_ТРЕБОВАНИЯ
    Текст раздела...

    Возвращает словарь {раздел: текст}
    """
    import re

    # Читаем файл
    with open(file_path, "r", encoding="utf-8") as f:
        content = f.read()

    # Регулярка для поиска разделов: ## N. НАЗВАНИЕ
    section_pattern = re.compile(
        r"##\s*(\d+)\.\s*([А-Я_]+)\s*\n(.*?)(?=\n##\s*\d+\.|$)",
        re.DOTALL | re.IGNORECASE,
    )

    result = {}
    matches = section_pattern.findall(content)

    for num, name, text in matches:
        # Очищаем текст от лишних пробелов и переносов
        clean_text = text.strip()
        # Убираем маркеры списков (-, *, 1., и т.д.)
        clean_text = re.sub(r"^[\s\-*0-9.]+\s*", "", clean_text, flags=re.MULTILINE)
        result[name] = clean_text

    return result


def parse_interviews_folder(folder_path: Path, markers: List[str]) -> Dict[str, str]:
    """
    Парсит все файлы интервью в папке и объединяет результаты.
    markers — список разделов для поиска.
    """
    import re

    combined_data = {}

    # Поддерживаемые форматы
    extensions = [".txt", ".md", ".docx"]

    for ext in extensions:
        for file_path in folder_path.glob(f"*{ext}"):
            print(f"   📄 Обрабатываю: {file_path.name}")
            try:
                if ext == ".docx":
                    # Читаем DOCX через python-docx
                    if Document is not None:
                        doc = Document(file_path)
                        content = "\n".join([para.text for para in doc.paragraphs])
                    else:
                        continue
                else:
                    # TXT или MD
                    with open(file_path, "r", encoding="utf-8") as f:
                        content = f.read()

                # Парсим разделы с переданными маркерами
                section_data = parse_interview_from_text(content, markers)

                # Объединяем с существующими данными
                for key, value in section_data.items():
                    if key in combined_data:
                        combined_data[key] += f"\n\n{value}"
                    else:
                        combined_data[key] = value

            except Exception as e:
                print(f"   ⚠️ Ошибка обработки {file_path.name}: {e}")

    return combined_data


def parse_interview_from_text(content: str, markers: List[str]) -> Dict[str, str]:
    """
    Парсит текст интервью и извлекает данные по заданным маркерам (разделам).
    markers — список разделов, которые нужно найти (например, из шаблона).
    """
    import re

    result = {}

    for marker in markers:
        # Ищем маркер в формате ## N. НАЗВАНИЕ
        pattern = re.compile(
            rf"##\s*\d+\.\s*{marker}\s*\n(.*?)(?=\n##\s*\d+\.|$)",
            re.DOTALL | re.IGNORECASE,
        )
        match = pattern.search(content)
        if match:
            text = match.group(1).strip()
            # Очищаем от маркеров списков
            text = re.sub(r"^[\s\-*0-9.]+\s*", "", text, flags=re.MULTILINE)
            result[marker] = text
        else:
            # Пробуем найти просто упоминание раздела без номера
            simple_pattern = re.compile(
                rf"{marker}\s*\n(.*?)(?=\n\s*[А-Я_]+|$)", re.DOTALL | re.IGNORECASE
            )
            simple_match = simple_pattern.search(content)
            if simple_match:
                text = simple_match.group(1).strip()
                result[marker] = text
            else:
                # Если раздел не найден, оставляем пустую строку
                result[marker] = ""

    return result

def extract_json_from_text(text: str) -> dict | None:
    """
    Извлекает JSON из текста, используя несколько стратегий.
    Возвращает dict или None.
    """
    import json
    import re

    if not text:
        return None

    # 1. Ищем JSON в кодовом блоке ```json ... ``` (берём ВСЁ содержимое)
    code_block_match = re.search(r"```json\s*([\s\S]*?)\s*```", text, re.DOTALL)
    if code_block_match:
        json_str = code_block_match.group(1).strip()
        try:
            return json.loads(json_str)
        except json.JSONDecodeError:
            pass

    # 2. Ищем JSON с ключами "tool" и "params" (для MCP-команд)
    json_match = re.search(
        r'\{[^{}]*"tool"\s*:\s*"[^"]+"\s*,\s*"params"\s*:\s*\{[^{}]*\}\s*\}',
        text,
        re.DOTALL,
    )
    if json_match:
        try:
            return json.loads(json_match.group(0))
        except json.JSONDecodeError:
            pass

    # 3. Ищем сбалансированный JSON (открывающая { и закрывающая })
    try:
        start = text.find("{")
        if start != -1:
            depth = 0
            for i, char in enumerate(text[start:], start):
                if char == "{":
                    depth += 1
                elif char == "}":
                    depth -= 1
                    if depth == 0:
                        potential_json = text[start : i + 1]
                        try:
                            parsed = json.loads(potential_json)
                            if isinstance(parsed, dict):
                                return parsed
                        except json.JSONDecodeError:
                            pass
                        break
    except Exception:
        pass

    # 4. Пробуем распарсить весь текст как JSON
    try:
        return json.loads(text.strip())
    except json.JSONDecodeError:
        pass

    # 5. Пытаемся исправить JSON (дополнительный этап)
    try:
        # Убираем завершающие запятые перед } или ]
        fixed_text = re.sub(r",\s*\}", "}", text)
        fixed_text = re.sub(r",\s*\]", "]", fixed_text)
        # Убираем лишние запятые
        fixed_text = re.sub(r",\s*,", ",", fixed_text)
        # Ищем JSON после исправления
        start = fixed_text.find("{")
        if start != -1:
            depth = 0
            for i, char in enumerate(fixed_text[start:], start):
                if char == "{":
                    depth += 1
                elif char == "}":
                    depth -= 1
                    if depth == 0:
                        potential_json = fixed_text[start : i + 1]
                        try:
                            parsed = json.loads(potential_json)
                            if isinstance(parsed, dict):
                                return parsed
                        except json.JSONDecodeError:
                            pass
                        break
    except Exception:
        pass

    return None

# ==================== ПАРСЕР ЗАПРОСОВ НА СОЗДАНИЕ ФАЙЛОВ ====================


def parse_file_request(
    message: str, project_name: str = "Проект", block_name: str = "Блок"
) -> dict | None:
    """
    Парсит запрос пользователя и возвращает готовый JSON для MCP-инструмента.
    Возвращает None, если запрос не просит создать файл.
    """
    import re
    import json

    print(f"\n🔍 ПАРСЕР: обрабатываю запрос:")
    print(f"   {message}")

    msg_lower = message.lower()

    # ===== ТОЛЬКО ЯВНЫЕ КОМАНДЫ НА СОЗДАНИЕ ФАЙЛОВ =====
    file_keywords = [
        "создай",
        "сделай",
        "сгенерируй",
        "word",
        "ворд",
        "docx",
        "doc",
        "excel",
        "ексел",
        "xlsx",
        "xls",
        "ppt",
        "pptx",
        "презентац",
        "xml",
        "таблиц",
        "отчёт",
        "документ",
    ]

    # 0. Чтение файлов из папки
    if any(
        kw in msg_lower
        for kw in ["прочитай файлы", "покажи содержимое папки", "прочитай папку"]
    ):
        print(f"   📂 Распознана команда чтения папки")

        folder_match = re.search(
            r"папк[иа]\s+([A-Za-z]:[\\\/][^\s,;.]+)", message, re.IGNORECASE
        )
        if not folder_match:
            folder_match = re.search(r'["\']([^"\']+)["\']', message)

        if folder_match:
            folder_path = folder_match.group(1)
        else:
            folder_path = ""

        return {
            "tool": "read_files_from_folder",
            "params": {"folder_path": folder_path},
        }

    if not any(kw in msg_lower for kw in file_keywords):
        print(f"   ❌ Не похоже на запрос файла")
        return None

    print(f"   ✅ Похоже на запрос файла")

    # ===== НОВЫЙ БЛОК: ИЗУЧЕНИЕ МЕТОДОЛОГИИ =====
    # Проверяем, есть ли команда "изучить методологию"
    study_keywords = ["изучи", "прочитай", "ознакомься", "изучить", "прочитать"]
    methodology_keywords = ["стандарт", "методологи", "гост", "pmbok", "prince", "методик"]

    if any(kw in msg_lower for kw in study_keywords) and any(kw in msg_lower for kw in methodology_keywords):
        print(f"   📚 Распознана команда изучения методологии")

        # Извлекаем путь к файлу
        file_match = re.search(
            r"([A-Za-z]:[\\\/][^\s,;]+\.(docx|pdf|txt|md))", message, re.IGNORECASE
        )
        if file_match:
            file_path = file_match.group(1)
            print(f"   📄 Найден путь к файлу: {file_path}")
            return {
                "tool": "study_methodology",
                "params": {"file_path": file_path}
            }
        else:
            print(f"   ⚠️ Путь к файлу не найден")
            return None
    # ============================================

    # ===== НОВЫЙ БЛОК: ЗАПОМНИТЬ ФАЙЛ =====
    remember_keywords = ["запомни", "запомнить", "сохрани в память", "прочти и запомни"]
    if any(kw in msg_lower for kw in remember_keywords):
        print(f"   🧠 Распознана команда запоминания файла")
        file_match = re.search(r"([A-Za-z]:[\\\/][^\s,;.]+)", message)
        if file_match:
            file_path = file_match.group(1)
            print(f"   📄 Найден путь к файлу: {file_path}")
            return {"tool": "remember_file", "params": {"file_path": file_path}}
        else:
            print(f"   ⚠️ Путь к файлу не найден")
            return None
    # ====================================

    # ===== ИЗВЛЕКАЕМ project_name И block_name =====
    project_match = re.search(r"проект\s*[::]\s*([^,;.]+)", message, re.IGNORECASE)
    block_match = re.search(r"блок\s*[::]\s*([^,;.]+)", message, re.IGNORECASE)

    if project_match:
        final_project_name = project_match.group(1).strip()
    else:
        final_project_name = project_name

    if block_match:
        final_block_name = block_match.group(1).strip()
    else:
        final_block_name = block_name

    print(f"   📁 Проект: {final_project_name}, Блок: {final_block_name}")

    # --- ОПРЕДЕЛЯЕМ ТИП ФАЙЛА ---

    # 0. Создание ТЗ из данных в папке
    if any(kw in msg_lower for kw in ["сделай тз", "создай тз", "тз из данных"]):
        print(f"   📄 Распознана команда создания ТЗ из данных")
        print(f"   📝 Сообщение: {message}")

        # Извлекаем путь к папке
        folder_path = ""
        folder_match = re.search(
            r"папк[иеи]\s+([A-Za-z]:[\\\/][^\s,;.]+)", message, re.IGNORECASE
        )
        if not folder_match:
            folder_match = re.search(r'["\']([^"\']+)["\']', message)
        if not folder_match:
            folder_match = re.search(r"([A-Za-z]:[\\\/][^\s,;.]+)", message)

        if folder_match:
            folder_path = folder_match.group(1)
            print(f"   📂 Найден путь к папке: {folder_path}")
        else:
            print(f"   ⚠️ Путь к папке не найден")

        # ===== ИЗВЛЕКАЕМ ШАБЛОН =====
        template_path = None

        # Ищем "шаблону X:\путь\файл.docx" с расширением
        template_match = re.search(
            r"шаблон[уе]?\s+([A-Za-z]:[\\\/][^\s,;]+)", message, re.IGNORECASE
        )
        if not template_match:
            # Ищем "по шаблону X:\путь\файл.docx"
            template_match = re.search(
                r"по\s+шаблон[уе]?\s+([A-Za-z]:[\\\/][^\s,;]+)", message, re.IGNORECASE
            )
        if not template_match:
            # Ищем шаблон в кавычках
            template_match = re.search(
                r'шаблон[уе]?\s+["\']([^"\']+)["\']', message, re.IGNORECASE
            )

        if template_match:
            template_path = template_match.group(1)
            print(f"   📄 Найден путь к шаблону: {template_path}")
        else:
            print(f"   ℹ️ Шаблон не указан, будет использован поиск в папке")
        # =====================================

        return {
            "tool": "create_doc_from_folder",
            "params": {
                "folder_path": folder_path,
                "project_name": final_project_name,
                "block_name": final_block_name,
                "template_path": template_path,
                "filename": "ТЗ_из_данных",
            },
        }

    # 1. Excel / XLSX / Таблица
    if any(kw in msg_lower for kw in ["excel", "xlsx", "ексел", "таблиц"]):
        # ... (весь остальной код Excel — без изменений)
        print(f"   📊 Распознан Excel")

        headers_text = ""
        rows_text = ""

        headers_pos = re.search(r"заголовки?\s*[::]", message, re.IGNORECASE)
        rows_pos = re.search(r"строки?\s*[::]", message, re.IGNORECASE)

        if headers_pos:
            start = headers_pos.end()
            if rows_pos and rows_pos.start() > start:
                end = rows_pos.start()
                headers_text = message[start:end].strip()
            else:
                headers_text = message[start:].strip()

        if rows_pos:
            start = rows_pos.end()
            rows_text = message[start:].strip()

        if headers_text:
            headers = [h.strip() for h in headers_text.split(",")]
        else:
            headers = ["Данные"]

        print(f"   📋 Заголовки: {headers}")
        print(f"   📝 Текст строк: {rows_text[:100]}...")

        rows = []
        if rows_text:
            row_parts = []
            current_row = ""
            for char in rows_text:
                if char == ";":
                    if current_row.strip():
                        row_parts.append(current_row.strip())
                    current_row = ""
                else:
                    current_row += char
            if current_row.strip():
                row_parts.append(current_row.strip())

            if not row_parts:
                row_parts = [rows_text]

            for row in row_parts:
                cells = [c.strip() for c in row.split(",")]
                while len(cells) < len(headers):
                    cells.append("")
                if len(cells) > len(headers):
                    cells = cells[: len(headers)]
                rows.append(cells)
        else:
            rows = [[""] * len(headers)]

        if not rows:
            rows = [[""] * len(headers)]

        result = {
            "tool": "create_xlsx",
            "params": {
                "project_name": final_project_name,
                "block_name": final_block_name,
                "filename": "Таблица_данных",
                "data": {"headers": headers, "rows": rows},
            },
        }
        print(f"   ✅ Результат: {json.dumps(result, ensure_ascii=False)[:200]}...")
        return result

    # 2. Word / DOCX / Отчёт / Документ
    elif any(kw in msg_lower for kw in ["word", "docx", "отчёт", "ворд", "документ"]):
        content_match = re.search(
            r"содержание\s*[::]\s*(.+?)(?=\.\s*$|$)", message, re.IGNORECASE
        )
        if content_match:
            content = content_match.group(1).strip()
        else:
            content = message

        return {
            "tool": "create_docx",
            "params": {
                "project_name": final_project_name,
                "block_name": final_block_name,
                "filename": "Документ",
                "content": content,
            },
        }

    # 3. PowerPoint / PPTX / Презентация
    elif any(kw in msg_lower for kw in ["ppt", "pptx", "презентац"]):
        print(f"   📽️ Распознана презентация")

        slides = []

        slide_pattern = re.compile(
            r"(?:первый|второй|третий|четвёртый|пятый|\d+)\s*слайд\s*[::]\s*([^,;.]+?)\s*,\s*текст\s*[::]\s*([^,;.]+)",
            re.IGNORECASE,
        )
        matches = slide_pattern.findall(message)

        if matches:
            for title, content in matches:
                slides.append({"title": title.strip(), "content": content.strip()})
            print(f"   📄 Найдено слайдов: {len(slides)}")
        else:
            for i in range(1, 10):
                pattern = re.compile(
                    rf"{i}\s*слайд\s*[::]\s*([^,;.]+?)\s*,\s*текст\s*[::]\s*([^,;.]+)",
                    re.IGNORECASE,
                )
                match = pattern.search(message)
                if match:
                    slides.append(
                        {
                            "title": match.group(1).strip(),
                            "content": match.group(2).strip(),
                        }
                    )
                    print(
                        f"   📄 Слайд {i}: {match.group(1).strip()} → {match.group(2).strip()[:30]}..."
                    )
                else:
                    pattern2 = re.compile(
                        rf"{i}\s*слайд\s*[::]\s*([^,;.]+?)\s*[::]\s*([^,;.]+)",
                        re.IGNORECASE,
                    )
                    match2 = pattern2.search(message)
                    if match2:
                        slides.append(
                            {
                                "title": match2.group(1).strip(),
                                "content": match2.group(2).strip(),
                            }
                        )
                        print(
                            f"   📄 Слайд {i}: {match2.group(1).strip()} → {match2.group(2).strip()[:30]}..."
                        )

        if not slides:
            print(f"   ⚠️ Слайды не найдены, создаю один")
            slides = [{"title": "Слайд 1", "content": "Содержание презентации"}]

        result = {
            "tool": "create_pptx",
            "params": {
                "project_name": final_project_name,
                "block_name": final_block_name,
                "filename": "Презентация",
                "slides": slides,
            },
        }
        print(f"   ✅ Результат: {json.dumps(result, ensure_ascii=False)[:200]}...")
        return result

    # 4. XML
    elif "xml" in msg_lower:
        data = {}
        data_matches = re.findall(r"(\w+)\s*[::]\s*([^,;.]+)", message, re.IGNORECASE)
        for key, value in data_matches:
            key = key.strip().lower()
            if key not in [
                "проект",
                "блок",
                "файл",
                "создай",
                "сделай",
                "заголовки",
                "строки",
                "содержание",
            ]:
                data[key] = value.strip()

        if not data:
            data = {"message": "Данные для XML"}

        return {
            "tool": "create_xml",
            "params": {
                "project_name": final_project_name,
                "block_name": final_block_name,
                "filename": "data",
                "root_tag": "root",
                "data": data,
            },
        }

    return None

@app.post("/methodology/study")
async def study_methodology(request: dict):
    """
    Изучает методологию и возвращает её структуру.
    Поддерживает: PDF, DOCX, TXT, MD.
    """
    import re
    from pathlib import Path
    import json

    file_path = request.get("file_path")
    if not file_path:
        return {"status": "error", "message": "Не указан путь к файлу"}

    path = Path(file_path)
    if not path.exists():
        return {"status": "error", "message": f"Файл не найден: {file_path}"}

    print(f"📚 Изучение методологии: {path.name}")

    # Если передан путь к папке — ищем в ней файл методологии
    if path.is_dir():
        print(f"   📂 Передан путь к папке, ищем файл методологии...")
        # Ищем файлы с расширениями .docx, .pdf, .txt, .md
        for ext in ["*.docx", "*.pdf", "*.txt", "*.md"]:
            files = list(path.glob(ext))
            if files:
                path = files[0]  # Берём первый найденный файл
                print(f"   📄 Найден файл: {path.name}")
                break
        if path.is_dir():  # Если файл не найден
            return {
                "status": "error",
                "message": f"В папке {file_path} не найдено файлов методологии (.docx, .pdf, .txt, .md)",
            }

    # 1. Читаем файл в зависимости от расширения
    content = ""
    if path.suffix.lower() == ".pdf":
        try:
            import pypdf

            reader = pypdf.PdfReader(path)
            for page in reader.pages:
                content += page.extract_text() + "\n"
            print(f"   ✅ PDF прочитан, {len(reader.pages)} страниц")
        except ImportError:
            return {
                "status": "error",
                "message": "Библиотека pypdf не установлена. Установите: pip install pypdf",
            }
        except Exception as e:
            return {"status": "error", "message": f"Ошибка чтения PDF: {e}"}

    elif path.suffix.lower() in [".docx"]:
        try:
            from docx import Document

            doc = Document(path)
            for para in doc.paragraphs:
                content += para.text + "\n"
            print(f"   ✅ DOCX прочитан, {len(doc.paragraphs)} параграфов")
        except ImportError:
            return {
                "status": "error",
                "message": "Библиотека python-docx не установлена. Установите: pip install python-docx",
            }
        except Exception as e:
            return {"status": "error", "message": f"Ошибка чтения DOCX: {e}"}

    elif path.suffix.lower() in [".txt", ".md"]:
        try:
            with open(path, "r", encoding="utf-8") as f:
                content = f.read()
            print(f"   ✅ TXT/MD прочитан, {len(content)} символов")
        except Exception as e:
            return {"status": "error", "message": f"Ошибка чтения файла: {e}"}

    else:
        return {"status": "error", "message": f"Неподдерживаемый формат: {path.suffix}"}

    if not content.strip():
        return {"status": "error", "message": "Файл пуст или не содержит текста"}

    # 2. Извлекаем структуру (заголовки)
    structure = extract_structure_from_text(content)

    # 3. Возвращаем результат
    return {
        "status": "ok",
        "filename": path.name,
        "structure": structure,
        "content_preview": content[:500] + ("..." if len(content) > 500 else ""),
        "total_chars": len(content),
    }


def extract_structure_from_text(text: str) -> List[str]:
    """
    Извлекает структуру документа из текста (заголовки, разделы).
    """
    import re

    # Ищем заголовки по шаблонам:
    # - В MD: # Заголовок, ## Заголовок
    # - В нумерованных: 1. Заголовок, 1.1 Заголовок
    # - В тексте: Глава 1. Заголовок, Раздел 1. Заголовок
    headers = []

    # 1. Markdown заголовки (#, ##, ###)
    md_headers = re.findall(r"^(#{1,6})\s+(.+)$", text, re.MULTILINE)
    for level, title in md_headers:
        headers.append(title.strip())

    # 2. Нумерованные заголовки (1. Заголовок, 1.1 Заголовок)
    num_headers = re.findall(r"^(\d+\.\d+|\d+\.)\s+(.+)$", text, re.MULTILINE)
    for num, title in num_headers:
        if title.strip() not in headers:
            headers.append(title.strip())

    # 3. Заголовки с ключевыми словами (Глава, Раздел, Часть)
    keyword_headers = re.findall(
        r"^(Глава|Раздел|Часть|Приложение)\s+(\d+\.?\d*)\s*[.:]?\s*(.+)$",
        text,
        re.MULTILINE | re.IGNORECASE,
    )
    for keyword, num, title in keyword_headers:
        full_title = f"{keyword} {num}. {title.strip()}"
        if full_title not in headers:
            headers.append(full_title)

    # 4. Если заголовков не найдено — пытаемся найти разделы по ключевым словам
    if not headers:
        common_sections = [
            "Введение",
            "Объект автоматизации",
            "Цель",
            "Задачи",
            "Требования",
            "Функциональные требования",
            "Технические требования",
            "Состав работ",
            "Методология",
            "Алгоритмы",
            "Отчетность",
            "Контроль",
            "Поддержка",
            "Заключение",
            "Список литературы",
        ]
        found_sections = []
        for section in common_sections:
            if re.search(rf"\b{section}\b", text, re.IGNORECASE):
                found_sections.append(section)
        if found_sections:
            headers = found_sections

    # 5. Если ничего не найдено — возвращаем пустой список
    if not headers:
        print("   ⚠️ Не удалось извлечь структуру")
        return []

    # Убираем дубли
    unique_headers = []
    seen = set()
    for h in headers:
        if h.lower() not in seen:
            seen.add(h.lower())
            unique_headers.append(h)

    print(f"   📋 Извлечена структура: {len(unique_headers)} разделов")
    return unique_headers

    def search(self, agent_name: str, query: str, limit: int = 5) -> List[Dict[str, Any]]:
        """
        Выполняет поиск по памяти агента через FTS5 (быстро и дёшево).
        """
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        # Экранируем спецсимволы для FTS5
        query = query.replace('"', '').replace("'", "")
        
        # Поиск через FTS5
        cursor.execute("""
            SELECT c.id, c.content, f.filename, f.agent_name
            FROM memory_fts fts
            JOIN memory_chunks c ON c.fts_content = fts.content
            JOIN memory_files f ON c.file_id = f.id
            WHERE f.agent_name = ? AND f.status = 'indexed' 
            AND memory_fts MATCH ?
            ORDER BY rank
            LIMIT ?
        """, (agent_name, query, limit))
        
        results = []
        for row in cursor.fetchall():
            results.append({
                "id": row[0],
                "content": row[1],
                "filename": row[2],
                "agent_name": row[3],
            })
        
        conn.close()
        return results
